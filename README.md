# 🧠 Study Buddy

A simple, modern study web app built with Flask.

## V1

- Subject selection
- Maths, Science, English and French quizzes
- Instant scoring
- Answer review
- Responsive interface
- Render deployment configuration

## Run locally

```bash
pip install -r requirements.txt
python app.py
```

Then open `http://localhost:5000`.

## Render

The repository includes `render.yaml` and uses Gunicorn for production.
